# StudyPilot · AI 学习资料总结平台 — 项目方案

> 一句话：一个 **Windows 免安装小工具**。把课程 PPT / PDF / Word / 视频 / 音频拖进来，AI 自动生成一份结构化 **PDF 学习报告**——包含知识大纲、核心重点、学习方法、复习计划、就业价值分析和轻重缓急判断。从 GitHub 下载、解压、双击 exe 就能用。

> ✅ **最终确认的决策（2026-11-02）**
> 1. **AI 接口**：默认 DeepSeek，同时兼容任意 OpenAI 兼容接口（硅基流动/通义/智谱/Moonshot/OpenAI/Ollama/LM Studio/自定义），界面可切换。
> 2. **音视频转录**：本地 **faster-whisper**，尽可能离线，不依赖云端 ASR。
> 3. **界面形态**：自动打开浏览器（本地 Web 界面）。
> 4. **项目名称**：**学伴**（StudyPilot）。
> 5. **开源协议**：MIT。
> 6. **测试资料**：已有两份 Python 基础语法 PDF，已用于跑通全流程验证。

## 1. 需求拆解与产品定位

### 1.1 输入 → 处理 → 输出

| 阶段 | 内容 |
|---|---|
| 输入 | 用户上传学习资料：PDF、PPT/PPTX、Word、TXT/Markdown、视频（MP4/MKV/MOV…）、音频（MP3/M4A/WAV…） |
| 处理 | ① 解析文档提取文字 ② 音视频抽音轨 → 语音转文字 ③ AI 分块提炼 → 合并成结构化知识报告 |
| 输出 | 一份排版好的 PDF：大纲 / 重点 / 学习方法 / 复习计划 / 就业关联 / 优先级 / 自测题 |

### 1.2 产品定位

- **形态**：本地桌面工具（Windows x64），非在线网站。所有文件在本机处理，只有"文本片段"会发给你配置的 AI 接口。
- **目标用户**：大学生、考研/考公党、转行自学者、想快速吃透一门网课的人。
- **核心价值**：把"看完 200 页 PPT / 3 小时视频"变成"5 分钟读一份重点报告"。
- **差异化**：免安装、体积小、中文优化、隐私友好（文件不出本机）、可换任意 AI 服务商。

### 1.3 功能范围

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0（MVP 必须） | 文档解析 | PDF / PPTX / DOCX / TXT / MD |
| P0 | AI 总结 | 分块提炼 + 合并成结构化报告 |
| P0 | PDF 生成 | 中文排版、封面、目录、章节 |
| P0 | 本地 Web 界面 | 拖拽上传、进度显示、下载 |
| P0 | 配置管理 | 填 API Key / 模型 / 接口地址 |
| P1 | 音视频转录 | 本地 faster-whisper，完全离线 |
| P1 | 多文件合并 | 一次上传多份资料，合成一份报告 |
| P1 | 报告风格档位 | 快速 / 标准 / 深度（影响 AI 调用次数与篇幅） |
| P2 | 扫描版 PDF OCR | 图片型 PDF 文字识别 |
| P2 | 自测题 + 答案 | 自动出题，检验学习效果 |
| P2 | 复习日历导出 | 生成 .ics 日历提醒 |
| P3 | 资料问答（RAG） | 就当前资料提问 |
| P3 | 本地模型 | 接 Ollama，完全离线 |

**明确不做**（至少 MVP 不做）：账号系统、云同步、多人协作、移动端 App、在线付费。这些都会让"轻量"目标失效。

## 2. 总体架构

```
┌──────────────────────────────────────────────────────┐
│  浏览器界面（纯 HTML/CSS/JS，零构建，随 exe 打包）      │
│  拖拽上传 → 实时进度 → 预览 → 下载 PDF                 │
└───────────────────────┬──────────────────────────────┘
                        │ HTTP 127.0.0.1:随机端口
┌───────────────────────▼──────────────────────────────┐
│  Flask 本地服务（单进程 + 后台线程）                    │
│  /api/upload  文件接收                                 │
│  /api/jobs    任务创建 / 查询进度                       │
│  /api/settings 配置读写                                │
│  /api/download PDF 下载                                │
└───────────────────────┬──────────────────────────────┘
                        │ 任务流水线
┌───────────────────────▼──────────────────────────────┐
│  Pipeline（分阶段、可断点）                            │
│  ① Extract 提取文字   ② Transcribe 转录（音视频）      │
│  ③ Map 分块提炼       ④ Reduce 合并结构化              │
│  ⑤ Render 渲染 PDF                                     │
└───┬──────────┬──────────────┬───────────┬────────────┘
    │          │              │           │
 PyMuPDF   imageio-ffmpeg   OpenAI SDK  ReportLab
 python-pptx  + 云语音识别   (兼容DeepSeek (中文字体)
 python-docx                /硅基流动/Ollama)
 openpyxl
```

设计要点：

- **单进程**：Flask 用线程跑耗时任务，不引入 Redis/Celery，保持轻量。
- **任务状态落盘**：每个任务一个 JSON 文件，断电/崩溃后能看历史，不做数据库。
- **断点续跑**：Map 阶段结果按块缓存，失败重试不重复烧 token。
- **零外部服务**：不需要服务器、数据库、消息队列。

## 3. 技术选型

### 3.1 运行形态对比（这是"点 exe 即用"的关键）

| 方案 | 包体大小 | 开发成本 | 文档解析生态 | 结论 |
|---|---|---|---|---|
| **Python + PyInstaller** | 解压后 55–65MB，zip 后 30–40MB | 低 | 最全（PDF/Office/音视频库成熟） | ✅ **推荐** |
| Tauri（Rust + Web） | 5–15MB | 高 | 弱，PDF/Office/ffmpeg 要自己桥接 | ❌ 为了小体积不值得 |
| Electron | 120MB+ | 中 | 一般 | ❌ 太重 |
| Go + Wails | 15–25MB | 中高 | 弱 | ❌ 解析库不成熟 |

**GUI 形态对比：**

| 形态 | 体验 | 打包复杂度 | 依赖 |
|---|---|---|---|
| 起本地服务 + 自动打开默认浏览器 | 好，像用网页 | 最低 | 无（系统自带浏览器） |
| pywebview 原生窗口 | 更像桌面软件 | 中 | 需 WebView2 运行时（Win11 自带，Win10 可能缺） |
| Tkinter 原生窗口 | 朴素 | 低 | 无 |

**推荐：Flask + 自动打开浏览器**。理由：零依赖、打包最简单、手机连同一 WiFi 也能访问（顺手多一个"投屏学习"场景）。后续想升级成原生窗口，加一层 pywebview 即可，不影响其余代码。

### 3.2 技术栈清单

| 层 | 选型 | 理由 |
|---|---|---|
| 语言/运行时 | Python 3.11 / 3.12 | 生态最全，打包成熟 |
| Web 框架 | Flask | 轻，单文件可跑 |
| 前端 | 原生 HTML/CSS/JS 单页 | 零构建、零 node_modules，打包即可用 |
| PDF 解析 | PyMuPDF (fitz) | 快、稳、体积可控 |
| PPT 解析 | python-pptx | 提取标题/正文/备注/文本框 |
| Word 解析 | python-docx | 段落 + 表格 |
| Excel 解析 | openpyxl | 表格转文本 |
| 编码检测 | chardet | 处理 GBK/UTF-8 混杂文本 |
| 音频解码 | PyAV（faster-whisper 内置） | 自带 ffmpeg 库，无需单独安装 ffmpeg |
| 语音识别 | **faster-whisper（本地）** | 完全离线；模型首次自动下载，默认 small |
| AI 总结 | openai SDK（自定义 base_url） | 一套代码兼容 DeepSeek / 硅基流动 / OpenAI / Ollama |
| PDF 生成 | ReportLab（Platypus） | 纯 Python，无系统依赖，中文可控 |
| 打包 | PyInstaller（onedir 模式） | 启动快、杀软误报少 |
| CI | GitHub Actions（windows-latest） | 打 tag 自动出 exe |

### 3.3 关键选型说明

**为什么 PDF 用 ReportLab 而不是 WeasyPrint/HTML 转 PDF？**
WeasyPrint 排版更漂亮，但 Windows 上依赖 GTK 运行库，打包体积和复杂度都会上去。ReportLab 是纯 Python，配合 Platypus 能做出封面、目录、章节、表格、页脚页码，足够专业，而且**体积小、零系统依赖**，与"轻量"目标一致。

**中文字体怎么办？**
ReportLab 生成中文 PDF 必须注册字体。方案：运行时优先加载 Windows 系统字体（`C:\Windows\Fonts\msyh.ttc` 微软雅黑，100% 存在于目标平台），找不到时回退 ReportLab 内置的 `STSong-Light` CID 字体。**这样不需要往 exe 里塞 10–20MB 字体文件**，体积更小。

**为什么 AI 走 API 而不是本地大模型？**
本地跑 7B 以上模型至少要 6–8GB 显存 + 几个 GB 模型文件，与"轻量化"直接冲突。API 方案软件体积小、效果更好、成本低（一份报告几毛钱）。同时保留 `base_url` 配置项，高级用户可接 Ollama 完全离线。

## 4. 核心模块设计

### 4.1 文件解析（Extract）

| 格式 | 处理方式 |
|---|---|
| PDF | PyMuPDF 逐页提取文字；检测到"几乎无文字"时标记为扫描件，提示用户（P2 接 OCR） |
| PPTX | 按页提取标题 + 正文 + 备注 + 表格，保留页码，便于报告引用 |
| DOCX | 段落 + 表格，保留标题层级（Heading 1/2/3 → 大纲结构） |
| TXT / MD | 编码检测后直接读取，Markdown 保留标题结构 |
| XLSX | 每个 sheet 转成文本表格 |
| 音视频 | 见 4.2 |

**通用输出**：统一成"带结构标记的纯文本"（`# 一级标题`、`## 二级标题`、页码/时间戳标注），让后续 AI 能识别层次，报告大纲才有据可依。

### 4.2 音视频转录（Transcribe）

```
视频/音频文件
   │ PyAV 直接解码音轨（faster-whisper 内置，无需外部 ffmpeg）
   ▼
本地 faster-whisper 模型（默认 small，首次自动下载到数据目录）
   │ CPU int8 量化；检测到 CUDA 时自动启用 GPU
   ▼
带 [mm:ss] 时间戳的完整文字稿
```

- **完全离线**：音频不离开本机；模型文件下载一次后即可断网使用（默认走 `hf-mirror.com` 镜像，可用 `HF_ENDPOINT` 覆盖）。
- **模型档位**：tiny 75MB / base 145MB / **small 466MB（默认）** / medium 1.5GB / large-v3 3.1GB，界面可切换。
- **长视频**：流式迭代转写，进度按已处理时长推进，可随时取消。
- **性能**：CPU 推理约为音频时长的 0.5–2 倍；NVIDIA 显卡 + CUDA 环境会自动加速。

### 4.3 AI 总结流水线（Map-Reduce）

这是产品的"大脑"，决定报告质量。

```
全文（可能 5–20 万字）
   │ 按标题层级切块，每块 ≤ 6000 汉字，重叠 200 字
   ▼
【Map】每块独立提炼 → JSON：
   { 章节标题, 核心要点[], 关键概念[], 易错点/难点[], 原文出处(页码/时间) }
   │
   ▼
【Reduce】把所有块的要点合并 → 二次调用 → 最终结构化 JSON：
   { 大纲、重点、学习方法、复习计划、就业分析、优先级、自测题 }
   │
   ▼
【兜底】JSON 解析失败自动重试；仍失败则降级为 Markdown 文本渲染
```

- **结构化输出**：优先用 `response_format={"type":"json_object"}`；模型不支持时，用"严格 JSON 模板 + 解析重试"。
- **分档**：
  - 快速档：单次 Map（超长截断）+ 单次 Reduce，约 2–3 次调用；
  - 标准档：完整 Map-Reduce，约 8–15 次调用；
  - 深度档：更细的块 + 二次审校（自检遗漏），约 20–30 次调用。
- **成本可控**：界面实时估算 token 与预估费用，超过阈值提示用户。
- **并发**：Map 阶段可 2–3 路并发（注意 API 限流，可配置）。

### 4.4 PDF 报告生成（Render）

- 引擎：ReportLab Platypus，A4 版式。
- 组成：封面页 → 目录（自动生成页码）→ 各章节 → 页脚页码。
- 样式：标题分级、重点用 ★ 数量标识、表格、可选的"四象限图"（用表格/色块绘制，不引入绘图库）。
- 输出位置：`%LOCALAPPDATA%\StudyPilot\output\报告名_时间戳.pdf`，同时提供浏览器下载。
- 字体：见 3.3。

### 4.5 Web 界面与任务系统

- 首页：拖拽区 + 文件列表（可删）+ 报告档位选择 + "开始生成"。
- 生成中：分阶段进度（解析 → 转录 → 提炼 → 排版），显示当前阶段与百分比，可取消。
- 完成：内嵌 PDF 预览（浏览器原生支持）+ 下载按钮 + "再生成一份"。
- 设置页：AI 接口地址 / API Key / 模型名 / 语音识别配置 / 报告语言风格。
- 任务系统：线程池跑任务，状态写 JSON；前端每 1 秒轮询（SSE 可选，MVP 用轮询即可）。

### 4.6 配置与密钥安全

- 配置文件：`%APPDATA%\StudyPilot\config.json`。
- API Key 存储：优先 Windows DPAPI 加密（`win32crypt` 或 ctypes 调 CryptProtectData，零额外依赖），也可退化为明文 + 明确提示。
- 优先级：环境变量 > 配置文件。
- 上传文件：存系统临时目录，任务结束后自动清理（可配置保留天数）。
- 隐私：文件本身不离开本机；只把提取出的文本片段发往用户自己配置的 AI 接口。README 里写清楚。

## 5. PDF 报告结构（产品核心）

一份报告默认 15–30 页，结构如下：

```
封面
  课程/资料名称（AI 概括）· 源文件列表 · 生成日期 · 由 StudyPilot 生成

目录（自动页码）

第 1 章  知识大纲
  以多级列表呈现整份资料的知识骨架，每节标注对应页码/视频时间点

第 2 章  核心重点
  按重要度排序（★1–5），每条包含：
    · 概念/结论
    · 一句话解释
    · 原文出处（页码或时间戳）
    · 为什么重要 / 常见考法

第 3 章  学习方法
  · 这门知识适合怎么学（理解型/记忆型/实操型判断）
  · 具体方法：费曼学习法、主动回忆、例题驱动、对比表格等
  · 建议的学习顺序与时间分配

第 4 章  复习计划
  · 间隔重复表：第 1 / 3 / 7 / 15 / 30 天分别复习什么
  · 每日 30 分钟任务清单（可直接照做）
  · 自测检查点

第 5 章  就业价值与技能关联
  · 这份知识对应的岗位方向（如：数据分析 / 前端 / 运营…）
  · 市场常见要求与薪资区间（AI 基于常识给参考，标注仅供参考）
  · 面试高频考点
  · 与哪些技能组合更有竞争力

第 6 章  轻重缓急（四象限）
  · 重要且紧急：必须立刻掌握的核心
  · 重要不紧急：长期积累、决定上限的
  · 紧急不重要：应付考试/面试的速成点
  · 不重要不紧急：可跳过或略读的
  · 每象限给出具体知识点清单与投入建议

第 7 章  自测题（可选）
  选择题 + 简答题，附参考答案与解析

附录
  关键词表 · 原文摘要 · 参考链接（若资料内有）
```

> 说明：第 5 章"就业价值"和薪资区间是 AI 基于公开常识的推断，报告里会标注"仅供参考，请以实际招聘信息为准"，避免误导。

## 6. 轻量化与"下载即用"发布方案

### 6.1 打包方式

- **PyInstaller `--onedir` 模式**（不是 onefile）。原因：onefile 每次启动要把几十 MB 解压到临时目录，启动慢且更容易被杀软误报；onedir 解压一次、双击秒开。
- 发布物：`StudyPilot-win64-v1.0.0.zip`（约 30–40MB）。
- 用户使用路径：GitHub Releases 下载 zip → 解压到任意目录 → 双击 `StudyPilot.exe` → 浏览器自动打开 → 填一次 API Key → 拖文件用。

### 6.2 体积控制策略

| 项目 | 体积 | 是否打包 |
|---|---|---|
| Python 运行时 + 标准库 | ~15MB | ✅ |
| PyMuPDF | ~22MB | ✅ |
| ReportLab + python-pptx + python-docx + openpyxl | ~12MB | ✅ |
| Flask + openai SDK + 依赖 | ~10MB | ✅ |
| **faster-whisper 运行时（ctranslate2 + onnxruntime + PyAV + tokenizers + numpy）** | **~120–180MB** | ✅ **本地离线转写的代价** |
| 语音模型文件 | 75MB–3GB | ❌ 运行时按需下载到数据目录，不进安装包 |
| 前端静态文件 | <1MB | ✅ |

**结论**：由于选择了本地 faster-whisper，**实测**完整包解压约 **376MB**、zip 压缩后约 **175MB**（含 PyMuPDF 的 layout/onnx 资源与 faster-whisper 依赖）。这是"完全离线语音转写"的必要成本；模型文件不打包，首次使用时按所选档位下载（tiny 75MB / small 466MB / large-v3 3.1GB）。

### 6.3 GitHub Actions 自动构建

```
push tag v*  →  windows-latest
   ├─ 安装 Python 3.12
   ├─ pip install -r requirements.txt
   ├─ pyinstaller study-pilot.spec
   ├─ 压缩 dist/StudyPilot/ → zip
   └─ 创建 GitHub Release 并上传 zip
```

好处：你自己的电脑不需要装任何开发环境；改完代码打个 tag 就自动产出 exe。

### 6.4 首次启动引导

1. 检测配置文件是否存在；
2. 不存在 → 打开设置页，展示 3 个推荐服务商（DeepSeek / 硅基流动 / OpenAI）的注册链接和价格说明；
3. 用户填 Key → 测试连接 → 保存；
4. 进入主界面。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 扫描版 PDF 无文字 | 无法总结 | 检测并明确提示；P2 接 OCR |
| AI 输出跑题/漏重点 | 报告质量差 | 强约束提示词 + JSON 校验 + 覆盖率自检重试 |
| 长文档超上下文 | 报错 | 分块 Map-Reduce + 单块截断策略 |
| 视频很大/很长 | 处理慢、成本高 | 时长上限 + 切片 + 进度提示 + 预估费用 |
| API Key 泄露 | 被盗刷 | DPAPI 加密存储 + README 安全提示 |
| PyInstaller 被杀软误报 | 用户不敢用 | onedir 模式 + 可选代码签名 + 提供提交误报说明 |
| 中文字体显示异常 | PDF 乱码 | 系统字体 + CID 字体双重回退 |
| onefile 启动慢 | 体验差 | 明确采用 onedir |
